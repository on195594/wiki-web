# Personal Growth Operating Model

## Summary
这页提供个人成长域的通用建模模板：把判断、表达、学习、执行和自我管理作为可观察能力，而不是保存某个人的学习记录或成长状态。

证据边界：这是自我管理框架，不是心理、教育或职业效果的实证保证；具体目标、记录和复盘应留在使用者自己的私有系统。

## Core objective
个人成长系统的目标是：
- 持续提升判断、表达、学习和执行能力
- 支撑职业升级与系统建设能力
- 反哺家庭沟通、教育参与和情绪稳定性
- 让自己在中长期保持可塑性，而不是被当前角色固化

## What growth includes
当前成长系统至少包括四类能力：
- 认知能力：理解、判断、抽象、建模
- 表达能力：写作、沟通、结构化输出
- 执行能力：把想法转成可运行流程和长期资产
- 自我管理能力：情绪、节奏、复盘、习惯（技能习得与真实压力下迁移应用的区分见 [coping-skill-application-and-imaginal-exposure](/concepts/coping-skill-application-and-imaginal-exposure)）

## Decision principles
### 1. Growth must serve the whole system
成长不是自嗨式输入收集，而应反向提升工作、家庭、财务和系统治理质量。

### 2. Output and structured feedback matter more than passive collection
真正的成长应更多表现为更好的页面、更稳定的方法、更清楚的判断，而不是收藏更多链接。按 K. Anders Ericsson 等（1993，*Psychological Review*；2016，《Peak》）关于**刻意练习（Deliberate Practice）与有目的练习（Purposeful Practice）**的研究（[Practice (learning method)](https://en.wikipedia.org/wiki/Practice_(learning_method))），单纯重复已熟练的动作（天真练习）在自动化后会很快停滞；能力提升依赖明确拆分的具体子目标、略高于当前舒适区的任务难度、即时信息反馈以及针对错误的反复修正。同时需注意实证边界：Macnamara、Hambrick 与 Oswald（2014，*Psychological Science*）的元分析表明，刻意练习对不同领域表现方差的解释力存在显著差异（棋类游戏约 26%、音乐 21%、体育 18%、教育 4%，而在规则开放、反馈滞后的复杂职业活动中比例更低），因此不能把练习时长机械等同于职业结果保证。

### 3. Small loops and low extraneous load beat grand plans
比起宏大却经常中断的计划，更重要的是低摩擦、可持续、可复盘的小闭环。按 John Sweller（1988，*Cognitive Science*；2010，*Educational Psychology Review*）的**认知负荷理论（Cognitive Load Theory）**（[Cognitive load](https://en.wikipedia.org/wiki/Cognitive_load)），工作记忆容量极为有限，学习与复盘设计应压缩由工具摩擦、上下文频繁切换和松散材料带来的**外在认知负荷（Extraneous Load）**，按子图式拆解高**内在认知负荷（Intrinsic Load）**任务，从而把工作记忆资源集中于构建长期知识图式与自动化规则的**相关认知负荷（Germane Load）**。同时，[Stadler et al.（2024）](https://doi.org/10.1016/j.chb.2024.108386)在一次学生信息搜集任务中发现，使用 LLM 的组虽报告较低认知负荷，却产出了质量较低的推理与论证；[Melumad & Yun（2025）](https://doi.org/10.1093/pnasnexus/pgaf316)报告了从 LLM 摘要学习相较于网页搜索更浅的知识获取。这些结果不等于证明长期能力退化或迁移能力下降。[推论] 使用 AI 时仍应保留独立推理练习，并通过后续独立任务检验迁移效果。

### 4. Identity should stay evolvable via double-loop learning
成长系统必须保留自我更新能力，避免被既有标签或阶段性成功锁死。借鉴 Chris Argyris 与 Donald Schön（1978，《Organizational Learning》）的**单环与双环学习（Single-Loop vs. Double-Loop Learning）**区分（[Organizational learning](https://en.wikipedia.org/wiki/Organizational_learning)）：单环复盘是在既有目标与假设不变的前提下修正执行动作；双环复盘则在偏差反复出现时重新审视底层的目标设定、价值排序与心智模型本身。

## Parameterized review variables
[推论] 以下是基于本页原则的可选回顾参数，不是经验证的成长评分量表。参数无仓库默认值，具体记录留在私有系统：
- 输入—产出转化比 `R`：同一回顾期选定的输入条目中，能追溯到正式知识页、可复用方法（图式构建 / Germane Load 产物）或实际决策修正（含双环目标校准）的条目数占比；输入条目去重，每条至多计一次，不能直接用异质产出数量除以阅读数量；
- 最小闭环周期 `P`：不依赖高强度冲刺、外在认知负荷可控即可稳定执行的回顾与有目的练习周期；
- 压力下迁移验证项 `V`：区分低压力阅读理解、AI 辅助即时表现与真实任务/高压场景下的有效独立调用（检验方法见 [coping-skill-application-and-imaginal-exposure](/concepts/coping-skill-application-and-imaginal-exposure)）。

## Interfaces with other domains
### 与 [work-and-career-operating-model](/concepts/work-and-career-operating-model) 的关系
成长系统直接影响职业竞争力、能力栈升级和长期选择权。

### 与 [family-education-operating-model](/concepts/family-education-operating-model) 的关系
成长系统影响你如何和家人沟通、如何参与教育、如何示范学习方式和面对问题的姿态。

### 与 [household-fund-layering-model](/concepts/household-fund-layering-model) 的关系
成长系统影响风险判断、延迟满足能力和是否能长期坚持稳健决策。

## Boundary
本页不直接承载：
- 读书清单
- 课程购买记录
- 每日学习打卡 SOP
- 单次复盘记录

这些适合进入更细化页面、方法层或日志层。

## Optional assistant support
在获得相应数据访问授权后，AI 助手可以支持：
- 成长主题归档
- 知识到方法的转化
- 输出项目跟踪
- 周期性成长回顾
- 将成长成果映射回职业、家庭和财务系统

这些能力示例不表示任何个人记录已经接入或自动化。

## Success criteria
这个 operating model 成立时，应看到：
- 输入和输出的比例更健康
- 成长内容更容易沉淀进 wiki 或 skill，而不是停留在对话里
- 职业、家庭和成长之间的反馈关系更清晰
- 成长不再是“有空再说”，而是 LifeOS 的基础域之一
